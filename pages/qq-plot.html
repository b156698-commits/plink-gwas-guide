01

QQ Plot 在看什麼？

QQ Plot（Quantile-Quantile Plot）會把實際觀察到的 GWAS P-values， 與在 null hypothesis 成立時理論上預期看到的 P-value 分布做比較。

它不是用來找某一個 SNP 在哪個 chromosome 上，而是用來看 整體 association test 的分布是否合理。

02

X 軸與 Y 軸代表什麼？

X

Expected −log10(P)

在沒有真正 association signal 的情況下， 根據 uniform P-value distribution 所得到的理論預期值。

Y

Observed −log10(P)

真正從 GWAS association test 得到的 P-values， 再轉換成 −log10(P)。

03

對角線代表什麼？

如果 observed P-values 與 null hypothesis 下的預期分布大致一致， QQ Plot 上的點會接近 45° diagonal reference line。

Expected 理論 P-value 分布
≈
Observed 實際 GWAS P-values
→
接近對角線 整體分布大致符合預期
04

偏離對角線怎麼判讀？

↗

尾端向上偏離

如果大部分點貼近對角線，但最尾端少數點明顯向上， 可能代表存在真正的 association signals。

⚠

整體提早偏離

如果很多點從很早就整體向上偏離， 需要考慮 population stratification、cryptic relatedness、 technical artifacts 或其他造成 test statistic inflation 的原因。

↘

整體低於預期

若大量點偏在對角線下方，也可能代表 test 結果較保守， 或模型、資料處理與校正方式影響了統計量分布。

06

Genomic Inflation Factor（λ）

QQ Plot 常會搭配 genomic inflation factor（通常記為 λ 或 λGC） 一起檢查 test statistics 是否整體偏高。

Concept
λGC = observed median χ² / expected median χ²

當 λGC 接近 1 時，表示整體 test statistic 的 median 與 null expectation 較接近。

不過 λGC 不能單獨判斷分析是否有問題。 在大型 sample size 或高度 polygenic trait 中，即使模型合理， λGC 也可能高於 1。因此 QQ Plot、λGC、sample size、population structure 與 trait architecture 應一起判讀。

07

注意事項

  • QQ Plot 的重點是看整體 P-value distribution，不是定位 chromosome 或 gene。
  • 只有尾端少數點偏離對角線，可能代表真正 association signals。
  • 若整體大量偏離，應檢查 population stratification、relatedness、batch effects、genotyping / imputation quality 與模型設定。
  • λGC 接近 1 通常較符合 null expectation，但不能把「λGC 必須等於 1」視為絕對規則。
  • QQ Plot 與 Manhattan Plot 應搭配閱讀：前者看整體分布，後者看 association signals 在 genome 上的位置。
