01

這一步在做什麼？

PCA 是一種 dimension reduction 方法，可以把大量 genotype variation 轉換成少數幾個 principal components（PCs）。 在 GWAS 中，這些 PCs 常用來描述樣本之間主要的遺傳差異與 population structure。

Genotype Data 大量 SNP 資訊
→
PCA 找出主要變異方向
→
PC1, PC2, ... 用較少維度描述樣本差異
02

為什麼 GWAS 要做 PCA？

不同 ancestry 或 subpopulation 的 allele frequencies 可能不同。 如果 phenotype 與 population structure 同時有關，沒有適當校正時， association analysis 可能受到 population stratification 的影響。

因此常見做法是使用前幾個 PCs 作為 covariates， 協助校正 population structure 對 association analysis 的影響。

PCA 不只是「畫圖分群」；在 GWAS 中，更重要的用途之一是產生可加入 regression model 的 covariates。
03

PLINK 指令

基本 PCA plink --bfile step5_ld_pruned --pca --out pca

PLINK 1.9 的 --pca 預設會由 variance-standardized relationship matrix 萃取前 20 個 principal components。

指定 PC 數量 plink --bfile step5_ld_pruned --pca 10 --out pca

例如 --pca 10 表示輸出前 10 個 principal components。 要保留多少 PCs 應依研究設計、資料結構與後續分析需求決定。

04

輸出檔案

pca.eigenvec

每個 sample 的 principal component scores。 預設前兩欄為 FID、IID，後面依序為 PC1、PC2、PC3 ...

pca.eigenval

各 principal component 對應的 eigenvalues， 每一行對應一個 PC。

--pca header

可要求 .eigenvec 加上 header。

--pca tabs

可讓 .eigenvec 使用 tab 分隔。

--pca var-wts

可額外輸出 variant weights；一般初學 QC 流程不一定需要。

05

如何解讀 PC？

常見做法是將 PC1 與 PC2 畫成 scatter plot， 觀察樣本是否形成不同群聚、是否有明顯 outliers， 或是否呈現與 ancestry / population structure 相符的分布。

PC2
PC1

這只是概念示意圖。PCA 群聚本身不應直接被解讀成固定的人種或族群分類， 實際解讀需要結合研究樣本來源與 metadata。

06

如何加入後續 Association Analysis？

PLINK 官方文件指出，top principal components 常被當作 association regression 的 covariates， 以協助校正 population stratification。

PCA 取得 PC1、PC2、PC3 ...
→
Covariate file 整理需要納入的 PCs
→
GWAS Model 在 regression 中進行調整

要放入幾個 PCs 並沒有唯一答案，應依 population structure、 研究設計與分析策略決定，而不是固定使用某個數量。

07

注意事項

  • PLINK 1.9 的 --pca 預設輸出前 20 個 PCs，也可以自行指定數量。
  • PCA 常使用 LD-pruned SNP set，避免高度相關 variants 對 PCs 造成過度影響。
  • .eigenvec 是 sample-level PC scores；.eigenval 則是各 PC 的 eigenvalues。
  • 前幾個 PCs 常可作為 association analysis 的 covariates，但納入數量沒有唯一固定標準。
  • PLINK 1.9 官方文件目前也會對 PCA / GRM 中存在 monomorphic variant 的情況提出警告，因此 PCA 前仍應確認資料品質。
