01

這張圖在看什麼？

Manhattan Plot 是 GWAS 最常見的結果圖之一。 圖上的每一個點通常代表一個 variant / SNP， 並依它所在的 chromosome 與 genomic position 排列。

因為整張圖會把不同 chromosome 上的大量 variants 一次畫出來， 若某個 genomic region 出現一串很高的點，看起來就像城市裡的高樓， 因而得名 Manhattan Plot。

02

X 軸與 Y 軸代表什麼？

X

Chromosome / Genomic Position

X 軸依 chromosome 排列，每個點的位置對應 variant 的 genomic position。 常見呈現方式會讓相鄰 chromosome 使用交錯顏色，方便視覺區分。

Y

−log10(P)

Y 軸通常將 association test 的 P-value 轉成 −log10(P)。因此 P-value 越小，點就會越高。

Example
P = 1 × 10−8 → −log10(P) = 8

因此圖上越高的點，代表 association evidence 越強。

03

顯著性線怎麼看？

Genome-wide significance

常見 human GWAS 門檻：P < 5 × 10⁻⁸

Suggestive threshold

可依研究設定，例如部分 studies 使用 P < 1 × 10⁻⁵

Suggestive significance 並沒有單一固定標準； 圖上是否畫第二條 suggestive line，以及使用哪個門檻，都應依該研究的定義。

04

Peak 怎麼看？

若某個 chromosome 區域出現多個相鄰 variants 同時具有很小的 P-values， Manhattan Plot 上會形成一個明顯的 peak。

單一高點 可能是強 association signal，但仍需要確認資料品質與鄰近 variants。
一整群高點 常代表同一 locus 中多個 variants 因 LD 而一起呈現 association signal。
跨過 significance line 代表該 variant 達到圖中所設定的 statistical significance threshold。

Peak 不應直接等同於「這個 SNP 就是 causal variant」。 真正的 causal interpretation 通常還需要 fine-mapping、functional annotation、 replication 或其他後續分析。

06

注意事項

  • Manhattan Plot 是 association result 的視覺化工具，不是 PLINK QC 指令。
  • Y 軸越高代表 P-value 越小，而不是 effect size 越大。
  • 跨過 genome-wide significance line 代表達到統計門檻，不代表已證明 causality。
  • 一個 locus 中可能有許多 SNP 因 LD 而形成同一個 peak。
  • 判讀 peak 時應同時查看 effect size、allele frequency、sample size、imputation quality 與區域 LD structure。
